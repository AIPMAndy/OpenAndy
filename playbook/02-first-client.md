# 从一次咨询到六年信任

> `[公开自述]` 这是整篇文章里最"小"、却最可复用的一段：作者第一次真正靠自己赚钱，不是靠融资、不是靠做大业务，而是疫情期间在空闲时间帮人改简历。
> `[本仓库整理]` 本手册把它拆成动作；所有数字来自 S1，未经独立审计。

## 事实线

| 时间 | 发生了什么 |
|---|---|
| 2020 | 还在腾讯工作，疫情期间用空闲时间给年轻人做职业咨询；最早一批客户不少来自闲鱼 |
| 交付内容 | 分析岗位、修改简历、整理项目、准备面试 |
| 早期反馈 | 有人拿到 Offer 后介绍朋友过来；也有人工作几年后再回来，从求职咨询变成职业发展咨询，再到副业、创业、企业项目合作 |
| 2020–2026 | 一做六年，累计 **1000 多位有完整文档记录的咨询客户**，成为后来 B 端生意最可靠的支撑 |
| 一个具体例子 | 一位学生四年前找他做求职辅导，还分享了业务经验与资源；后来持续为服务付费，并带来多家上市公司合作 |
| 2026-11 初 | 签下一份上市公司合作合同，是当月第三份 |

作者自己的结论有两句：

> "一个普通人第一次靠自己赚钱，未必需要创立一家公司。只要有一种别人愿意付钱购买的能力，就已经有了起点。"
>
> "我当年以为自己卖的是一次咨询，后来才发现，我积累的是一段可以持续很多年的信任关系。"

## 拆解：最小可复制的部分

### 1. 起点是「一种能力」，不是「一家公司」

`[本仓库整理]` 检查三件事，都成立才具备起步条件：

- 有一类人正卡在一个具体问题里（想进大厂、想转 AI、不知道简历怎么写）；
- 你比他们早走过几步，能把问题说清楚；
- 你能交付一个**看得见的东西**：改完的简历、整理好的项目、模拟面试的反馈。

缺任何一条，先补那条，不要先注册公司、做 Logo、搭网站。

### 2. 第一位客户来自"已有的地方"

`[公开自述]` 最早一批客户不少来自闲鱼。`[本仓库整理]` 这条的价值不在于"去闲鱼"，而在于：**先在已经有人聚集、且允许交易的地方，用最低成本验证有没有人愿意付钱**。不需要自建渠道。

### 3. 每次交付留下文档

`[公开自述]` 1000 多位客户的限定语是"**有完整文档记录的**"。`[本仓库整理]` 文档化的作用有三：

- 让第二次服务不必从零开始（降低边际成本）；
- 让问题和结果可复盘，而不是只留下印象；
- 在获得许可的前提下，才能沉淀成 anonymized 案例（本仓库不放任何客户细节）。

### 4. 把「一次成交」看成「关系的开始」

`[公开自述]` 有人从求职咨询走到职业发展咨询，再走到副业、创业与企业合作。`[本仓库整理]` 这里要克制的推论是：**信任有可能随时间复利，但不能预设**。作者没有说"每个客户都会带来上市公司合作"——那是一个例子，不是转化率。

按公理 5（概率不确定）：这是存在性证据，不构成概率估计。本仓库没有客户总体数据，不计算复购率或转介绍率。

### 5. 六年是成本，不是光环

`[公开自述]` "一个客户，一个客户地聊"，同时还在腾讯全职工作。`[本仓库整理]` 按公理 8（机会成本），这条路径的代价是六年的 evenings/weekends，以及被占用的恢复时间。把它写成"轻松的副业"是不诚实的。

## 可以直接照做的检查表

- [ ] 我能不能用一句话说清：帮**谁**解决**什么问题**、交付**什么东西**？
- [ ] 有没有一个人愿意为它付一次钱？（没有就先去找，不要先做产品）
- [ ] 这次交付有没有留下可复用的文档？
- [ ] 我有没有把"客户会长期回来"当成必然？
- [ ] 我有没有把占用的业余时间算进成本？
- [ ] 对外讲案例时，有没有去掉姓名、公司、岗位与联系方式？

## 边界

- 1000+ 是**有完整文档记录的咨询客户数**，不等于 Offer 数、不等于成功案例数，也不代表服务质量。
- "当月第三份合同""上市公司合作"均为作者自述，未披露客户与金额，本仓库不做业绩背书。
- 本文不构成求职、职业或创业建议；个人条件不同，请按可撤回的小步尝试验证。
