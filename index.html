我是谁

我开倒过店，创业交过学费，2024 年身体出问题，2026 年上了手术台；我也确实从零做过亿级业务线、带过 50 人左右的团队、六年攒下 1000 多位有完整记录的咨询客户、帮父母把农产品做到一年 40 万产值。两边都是真的，我都写进来。

赚钱的四层

这是我对自己赚钱方式的分类，不是普遍规律。四层可以同时存在，不需要按顺序毕业。

层卖什么约束与代价
1 时间上班一天、咨询一次线性、停手即停收；极限是「忙到忘记自己」
2 经验别人要花几年才有的行业判断仍需本人在场，经验要靠交付物证明
3 商业结果增收入、降成本、拿客户要对结果负责，举证责任转移
4 内容获客让内容先被看见，再谈合作持续投入、不能停（熵增）

九条判断规则 · 一页版

不是客观规律，是我做判断时真的在用的规则。用错场景会得出坏结论。

1 熵增有序要持续投入，没有一劳永逸
2 还原拆到基本事实，不靠类比
3 对立统一任何方案都有取舍，列出代价
4 演化选择快速试错筛选，不预设最优
5 概率不确定给置信度，不给断言
6 因果边界相关 ≠ 因果，需干预验证
7 有限理性求可验证的满意解
8 机会成本看增量，忽略沉没成本
9 系统涌现看元素，也看反馈回路
工程顺序质疑需求 → 删除 → 简化 → 加速 → 最后自动化

怎么用

零依赖，不安装、不联网、不要 API Key。脚本只做检索和一致性检查，不生成建议。

git clone https://github.com/AIPMAndy/OpenAndy.git
cd OpenAndy

python3 openandy.py list                # 10 个条目
python3 openandy.py ask 副业            # 关键词检索
python3 openandy.py show what-it-cost   # 输出某篇全文
python3 openandy.py check               # 查索引、链接、来源、隐私
python3 openandy.py build               # 重新生成 llms-full.txt

想让 AI 读：先给 llms.txt 和 AGENTS.md，再按需加载 llms-full.txt。

事实与边界

这段决定你该怎么用这里的东西：
  • 数字都是我自己说的，没审计。40 万是产值不是利润；30 万是月流水不是利润；1000+ 是客户数不是 Offer 数；6 万多是全网粉丝合计。
  • 年份只按 2026-11-07 那篇文章算。另外一些履历材料对不上，我不合并、不推断、不取中间值。
  • 客户、公司、金额、家人信息不写。能讲的是方法，不是别人的隐私。
  • 不给收益承诺，不做医疗、投资、职业建议。我的路径只有一条，样本量是 1。
  • 相关不等于因果。我做了什么、后来发生了什么，不等于前者导致后者。
