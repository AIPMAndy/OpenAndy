这个仓库是什么，不是什么

按「先删非必需项」的原则，先把容易变成内容农场的部分删掉，剩下的才值得维护。

是

  • 一条每一阶段都标注代价的时间线
  • 作者实际用来做判断的九条规则
  • 能直接打勾的决策清单与 5 份方法手册
  • 人和 AI 都可检索的索引：llms.txt / llms-full.txt / index.json
  • 每个数字都标明「自述、未经独立审计」

不是

  • 不是成功学：写进了开倒的店、白内障手术、"我还没有成功"
  • 不是课程或引流页：无付费墙、无转化漏斗
  • 不是简历：不补未公开的公司、客户、金额
  • 不是 AI 分身：不调用模型、不上传数据
  • 不是收益承诺：所有数字是历史自述，不是可复制结果
「我曾经以为，只要足够努力，一个人就能够改变自己的命运。后来才明白，努力只是最基本的条件。」

事实分级与口径

这个仓库最容易被误用的地方，是把「一个人的经验」当成「普遍规律」。引用时必须保留标记。

[公开自述]作者公开发表，未经独立审计
[工作原则]作者的思考规则，不是事实
[本仓库整理]推导出的清单，不是事实
[存疑]冲突或证据不足，不判断
口径不合并
任职年份在不同材料中不一致，本仓库只采用 2026-11-07 文章口径，不推断、不填平。
数字有定语
30 万是月流水不是利润；1000+ 是有文档记录的客户不是 Offer 数；40 万是产值不是净利润。
相关 ≠ 因果
企业业绩、健康变化、内容增长都未做归因验证，单一案例不构成因果论证。
隐私不进仓库
客户、雇主、合同金额、家庭身份信息与私人联系方式一律排除。

时间线：得到什么，付出什么

每个阶段强制写四栏：事实 / 当时判断 / 代价 / 可迁移的一条。下表是精简视图，全文见 STORY.md。

阶段得到付出
农村起点相信知识可以改变命运没有资源缓冲，犯错成本自负
初中失眠独立思考，不轻信标准答案两年独自承受，无专业帮助
大学创业30 万月流水、30 人团队开倒过店，学到流水 ≠ 利润
绿皮火车进入机会密度更高的市场离家、从零开始、无确定性
腾讯从零做出亿级 AI 业务线运营商务全包，时间被吞
副总裁规模、团队、融资经验健康、时间所有权；"钱不是我的"
六年副业1000+ 客户、长期信任六年并行投入，占恢复时间
2026 开源内容获客、可复用方法持续维护，放弃部分直接变现
转折点不是升职，是 2026-01-12 的眼睛手术：「如果赚钱的代价，是把身体、时间和生活全部交出去，那么赚到更多钱，到底是为了什么？」

赚钱的四层

作者对自己赚钱方式的分类框架，不是普遍规律，四层可以同时存在，不需要按顺序毕业。

层卖什么约束与代价
1 时间上班一天、咨询一次线性、停手即停收；极限是"忙到忘记自己"
2 经验别人要花几年才有的行业判断仍需本人在场，经验要靠交付物证明
3 商业结果增收入、降成本、拿客户要对结果负责，举证责任转移
4 内容获客让内容先被看见，再谈合作持续投入、不能停（熵增）

九条认知公理 · 一页版

作者用来做判断的规则，不是客观规律；用错场景会得出坏结论。

1 熵增
有序要持续投入，没有一劳永逸
2 还原
拆到基本事实，不靠类比
3 对立统一
任何方案都有取舍，列出代价
4 演化选择
快速试错筛选，不预设最优
5 概率不确定
给置信度，不给断言
6 因果边界
相关 ≠ 因果，需干预验证
7 有限理性
求可验证的满意解
8 机会成本
看增量，忽略沉没成本
9 系统涌现
看元素，也看反馈回路
工程顺序
质疑需求 → 删除 → 简化 → 加速 → 最后自动化

三个自检：加功能前问「能删什么」；优化前问「这段必要吗」；自动化前问「流程能否取消」。全文 → PRINCIPLES.md

30 秒上手

零依赖，不安装、不联网、不要 API Key。CLI 只做检索与一致性检查，不生成建议。

git clone https://github.com/AIPMAndy/OpenAndy.git
cd OpenAndy

python3 openandy.py list                # 列出全部条目
python3 openandy.py ask 副业            # 关键词检索
python3 openandy.py show money-layers   # 输出某篇全文
python3 openandy.py check               # 校验索引 / 链接 / 来源 / 隐私
python3 openandy.py build               # 重新生成 llms-full.txt

想让 AI 读：先给它 llms.txt 与 AGENTS.md，再按需加载 llms-full.txt。
